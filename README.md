# CERNIS PRO

LAN Scanner and Network Monitoring Desktop Application

## Stack
- Backend: FastAPI / Python
- Frontend: React / Vite
- Desktop: Tauri v2
- Distribution: PyInstaller + NSIS

## Build Targets
- Windows ARM64
- Windows x64
- Linux x64 (.deb)
- Linux x64 (.rpm)
- macOS ARM64
